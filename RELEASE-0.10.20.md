# Red-XAI Bridge 0.10.20 — desktop update

This update uses the normal Bridge installation and updater. It includes the red-and-black Windows installer with the X progress ring, direct verified CLI download, and independent terminal-only or crawler-only connections. The working 0.10.19 sign-in correction is preserved.

The shop is **Coming soon**. Subscriptions, free and paid plugins, Axioms, device enrollment, agreement acceptance, account-management and staff controls are inactive in this release. The pages show a local planned catalog; displayed prices and allowances are previews, not active entitlements. Purchasing and all account-platform operations are blocked in the main process, including direct IPC calls. No checkout, license grant, balance change or draft-agreement acceptance is possible through these pages.

A normal follow-up update will activate the shop after the account, database, business/legal, payment and server deployment checks pass. Installing this desktop update does not activate paid access or create a subscription.

Windows and Linux packages use the existing app identity and preserve settings, clients and approved folders. macOS distribution remains deferred.
