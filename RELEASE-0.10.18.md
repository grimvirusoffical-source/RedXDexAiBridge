# Red-XAI Bridge 0.10.18

The Windows installer now uses the metallic Red-XAI X with a transparent background for its file icon and circular installation progress display.

This release includes the red and black installer, live progress counter and status, and verified CLI download improvements from 0.10.17. Release publishing now selects the successful build artifacts correctly after a workflow retry.

Windows and Linux installers are included. Windows packages are unsigned; macOS has source/native/background checks but no signed installer in this release. Shop and account-platform preview features remain separate.
