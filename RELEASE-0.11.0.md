# Red-XAI Bridge 0.11.0 — platform preview

This candidate adds the red/black Windows installer with a native-progress X ring, a verified direct CLI download, independent terminal/crawler client credentials, plugin recipes, a six-tier membership catalog, Axioms, account controls, and owner/admin pages.

Platform commerce is NOT enabled in the stable app. The production account-authority adapter, protected RedX credentials, verified owner subject/MFA linkage, published agreements, Stripe server credential and signed webhook deployment must pass integration readiness first. Sandbox catalog creation and isolated fixtures are not evidence of a production deployment. Existing v0.10.16 remains the stable login repair.

Owner benefits are server-authoritative: all plugins and the highest tier free forever on unlimited enrolled devices, while normal authentication, device proof, tool permissions and emergency STOP remain required. Admins do not inherit owner benefits.

Plans apply across participating Red-XAI apps; this candidate implements Bridge-specific weekly active-work and crawler allowances. Idle/approval waits do not count. Ruby has unlimited active-work time; safety and network limits still apply. Axioms use integer hundredths ($1 = 1 AX; minimum top-up $5.01). Workflow Checkpoints is proposed at $3.99 once per enrolled device, with three verified recoveries per rolling year for purchased licenses.

No uploaded arbitrary plugin code executes. Published plugin recipes use existing approved tools. Workspace Snapshot, Cleanup Preview and Crawl Brief are free. Workflow Checkpoints stores file snapshots in encrypted local storage and asks before restoring files or running a user-specified build command.

Platform readiness and cross-platform/package QA remain required before stable promotion. This candidate is intentionally a preview, not a claim that live billing, global moderation or deletion have been deployed.
